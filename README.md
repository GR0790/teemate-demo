# 티메이트 (TeeMate) — 단체복·유니폼 간편견적 데모

사업 검토용 프로토타입입니다. `index.html`을 브라우저로 열면 바로 동작합니다(서버·빌드·인터넷 불필요).

- 라이브 데모: https://gr0790.github.io/teemate-demo/

## 파일
- `index.html` — 페이지 구조(랜딩 + 4단계 견적 빌더 + AI 시안 요청 + 견적서 모달)
- `styles.css` — 라이트 고정 디자인 시스템(화이트 + 딥네이비 #102A56 + 블루 #1F5AE0)
- `app.js` — 가격 엔진, SVG 목업 렌더링, 인터랙션, 정식 견적서 생성
- `fonts/PretendardVariable.woff2` — 본문 서체(오프라인 동작, 실패 시 시스템 폰트로 대체)
- 스크린샷(`preview-desktop.png`, `preview-mobile.png`, `quote-desktop.png` 등)은 저장소에는 올리지 않고 로컬 작업 폴더에만 보관합니다.

## 견적서
- 빌더에서 고른 품목·색상·수량·인쇄 위치·방식이 그대로 담기는 **정식 견적서 1종**만 발행합니다(‘견적서 보기 / PDF’ 버튼 또는 AI 시안 접수 완료 모달의 ‘견적서 보기’).
- 견적서에는 사업자 정보·견적일/유효기간·품목 사양·색상·수량·인쇄·장당/금액·수량 할인·공급가액·부가세·합계가 들어가고, 브라우저 인쇄로 PDF 저장이 됩니다.

## 가격 로직 (app.js 상단 상수에서 조정)
- 품목 기본가 `ITEMS[].base` = 10~29장 무지 단가
- 수량 구간 `TIERS` : 30장 -6% / 50장 -11% / 100장 -16% / 200장 -20% / 500장 -24%
- 인쇄비 `POSITIONS[].add`(가슴 3,500 · 등판 6,000 · 가슴+등판 8,500 · 소매 3,000) + `METHODS[].add`(나염 0 · DTF +1,000 · 자수 +3,500)
- 인쇄비 수량 할인 `PRINT_DISC()` : 30장 -500 … 500장 -2,000 (최저 1,200원)
- 장당 단가 = round10(무지 단가×(1-할인율) + 인쇄비), 총액 = 장당 × 수량, VAT 10% 별도

## 실제 런칭 시 바꿀 것
- 하단 사업자 정보·대표번호·계좌, 개인정보 처리방침 링크
- 견적서의 상호/사업자번호/직인 이미지
- 폼 전송(현재는 데모 모달만), 카카오톡 채널 링크, GA/구글애즈 전환 스크립트
- `ITEMS` 단가·원단·사이즈표를 실제 하청 공장 단가로 교체
